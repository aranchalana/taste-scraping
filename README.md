# NPS-scraping
Práctica 1 de Tipología y ciclo de vida de los datos (Máster en Data Science, UOC). Web scraping en Python del sitio del National Park Service (NPS) para construir un dataset sobre los parques y unidades del Sistema de Parques Nacionales de Estados Unidos, con información sobre su ubicación, designación, actividades, patrimonio natural y cultural, tarifas y horarios.
